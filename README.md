# Академія CannaMed — прототип фронтенду

Клікабельний прототип усіх екранів і станів з ТЗ v2 / списку фіч v3.
Призначення: узгодити обсяг фронтенду з клієнтом до появи Figma і підперти оцінку годин.

## Запуск

```bash
cd prototype
npm install
npm run dev     # http://localhost:5173
```

## Де що дивитися

**`/map` — карта прототипу.** Усі екрани з привʼязкою до ID фіч (F-01…F-71) і перелік станів S01–S14.

Демо-входи на `/login`: «Як лікар», «Як медпредставник», «Як адміністратор».
Статус заявки перемикається в кабінеті (вкладка «Статус доступу») — щоб показати стани
«очікує підтвердження», «підтверджено», «відхилено».

## Стек прототипу

- React 18 + Vite + React Router
- Zustand (+ `persist`) — стан фільтрів, збережених матеріалів, реєстрацій на події, прогресу тесту, згоди на cookie
- Чистий CSS з токенами брендбуку (`src/styles/global.css`): `#022622`, `#00AF5F`, `#37DB89`, `#C5F9D1`, `#FFFFFF`

> **Прод-стек — той самий: Vite + React + Zustand, без SSR.** Бекенд на Python, Node у проді
> не піднімаємо. SEO-вимоги п.10 ТЗ закриваються prerender-ом статичних маршрутів на білді
> (react-snap / vite-plugin-prerender) + мета-теги + базовий JSON-LD. Пересборка при публікації
> контенту — вебхук з CMS на білд-сервер (години на бекенді).
>
> Це свідомий компроміс: повноцінного SSR не буде, індексація динамічних сторінок залежить від
> регулярності пересборки. Зафіксувати з клієнтом письмово.

## Структура

```
src/
  components/   Layout (хедер, футер, cookie-банер, модалки, тости) + UI-примітиви
  pages/        Публічні сторінки, auth/, cabinet/, Admin, Map
  store/        authStore, uiStore, contentStore (бібліотека, події, пошук, курс)
  mock/data.js  Усі мокові дані — у проді замінюються на API CMS/LMS
  styles/       Дизайн-система в токенах
```

## Що свідомо НЕ реалізовано

- Реальний бекенд, авторизація, завантаження файлів (усе на моках у localStorage)
- Навчальна частина (плеєр, тести, сертифікати) показана як UI-демо — у базовому сценарії
  оцінки вона живе всередині LMS (Softbook / SendPulse), а не на нашому фронті
- SEO-метадані, schema.org, sitemap — потребують SSR, тому в прототипі відсутні
